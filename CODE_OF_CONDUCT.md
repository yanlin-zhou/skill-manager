# Community conduct

- Be respectful. Discuss the work without harassment or personal attacks.
- Share only content you have permission to publish. Keep personal Skills, credentials and company information private.
- Keep issues and pull requests focused and actionable. Explain the user problem and provide a minimal example.
- Maintainers may edit, close or remove content that violates these expectations and may restrict repeat offenders.

For abusive content, use GitHub's **Report content** action or the repository's **Contact repository admins** option where available. Security vulnerabilities belong in the private reporting channel linked in [SECURITY.md](SECURITY.md).
